# COREX OS

### Beyond the Core.

CoreX OS is an experimental, Android-based mobile operating system project designed to deliver a modern, intelligent, secure and highly customizable smartphone experience.

## Project Information

- **Project Name:** CoreX OS
- **Version:** 0.1.0
- **Codename:** Genesis
- **Target Device:** Xiaomi Redmi 6A
- **Device Codename:** cactus
- **Platform:** Android Open Source Project (AOSP)
- **Project Status:** Early Development

## Vision

Our vision is to develop an independent mobile operating system experience with a custom interface, intelligent system applications, enhanced privacy controls and a modern application ecosystem.

## Core Features

### 1. CoreX Launcher
- Custom Home Screen
- App Drawer

- Smooth Animations

### 2. CoreX Intelligence
- AI Assistant

### 3. CoreX System
